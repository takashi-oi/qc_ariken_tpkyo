# ページ別関数仕様書

## 1. メインアプリケーション (qc_ariken_tokyo.py)

### 1.1 概要
システムのエントリーポイント。メニュー画面を提供し、各ページへのナビゲーションを管理。

### 1.2 主要機能
- ページ設定（タイトル、レイアウト）
- メニュー表示
- ページリンク管理
- セッション状態管理

### 1.3 関数一覧
- `main()`: メイン処理（Streamlit自動実行）

### 2.2 主要機能
- ファイルアップロード
- データ解析
- WESTGARDルール判定
- 結果表示・確認

### 2.3 関数一覧
- `main()`: メイン処理
- `process_uploaded_file()`: アップロードファイル処理
- `analyze_data()`: データ解析
- `apply_westgard_rules()`: WESTGARDルール適用
- `display_results()`: 結果表示
