## 8. マスターテーブル管理 (pg99_master_table.py)

### 7.1 概要

マスターデータ（担当者、測定機器、測定パネル、QC_Control）の管理を行うページ。SQLite3データベースを使用し、ブラウザ上での直接データ入力・更新、Excelファイルのインポート・エクスポート機能を提供します。

### 7.2 主要機能

- **ブラウザ上での直接データ入力・更新**
  - Streamlitの`st.data_editor`を使用したインタラクティブなデータ編集
  - 空のテーブルからでも新規データを追加可能
  - 行の追加・削除・編集が可能
- **Excelファイルからのインポート**
  - Excelファイルをアップロードして一括インポート
  - テーブル構造が自動的に更新されます
- **Excelファイルへのエクスポート**
  - データベースの内容をExcel形式でダウンロード可能
- **動的テーブル構造更新**
  - DataFrameのカラムがテーブルに存在しない場合、自動的に追加
  - カラム名のエスケープ処理（特殊文字対応）
  - データ型の自動推測

### 7.3 クラス設計

```python
class MasterDatabaseManager:
    """マスターデータベース管理クラス"""
    
    def __init__(self, db_path: str):
        """データベース接続を初期化（SQLite3）"""
    
    def create_master_tables(self):
        """マスターテーブルを作成（存在しない場合のみ）"""
    
    def import_excel_to_db(self, excel_file, table_key: str) -> bool:
        """ExcelファイルからDBにデータをインポート"""
    
    def export_db_to_excel(self, table_name: str) -> bytes:
        """データベースからExcelファイルをエクスポート"""
    
    def migrate_excel_to_db(self, table_key: str) -> bool:
        """既存のExcelファイルからDBにデータを移行"""
    
    def load_master_data(self, table_name: str, force_reload: bool = False) -> pd.DataFrame:
        """マスターデータを読み込む（キャッシュ付き）"""
    
    def update_table_structure(self, table_name: str, df: pd.DataFrame) -> bool:
        """テーブル構造をDataFrameのカラムに合わせて更新"""
    
    def save_master_data(self, df: pd.DataFrame, table_name: str) -> tuple[bool, str]:
        """マスターデータを保存（成功フラグとエラーメッセージを返す）"""
    
    def check_table_has_data(self, table_name: str) -> bool:
        """テーブルにデータが存在するか確認"""
    
    def get_table_schema(self, table_name: str) -> list:
        """テーブルのスキーマ（カラム名）を取得"""
    
    def create_empty_dataframe(self, table_name: str) -> pd.DataFrame:
        """テーブルのスキーマに基づいて空のDataFrameを作成"""
    
    def ensure_table_structure(self, table_name: str, df: pd.DataFrame) -> bool:
        """テーブルが存在しない場合、DataFrameの構造に基づいてテーブルを作成"""
    
    def close(self):
        """接続を閉じる"""
```

### 7.4 関数一覧

#### 7.4.1 MasterDatabaseManagerクラス

- `__init__(db_path: str)`: データベース接続を初期化
- `create_master_tables()`: マスターテーブルを作成（存在しない場合のみ）
- `import_excel_to_db(excel_file, table_key: str) -> bool`: ExcelファイルからDBにデータをインポート
- `export_db_to_excel(table_name: str) -> bytes`: データベースからExcelファイルをエクスポート
- `migrate_excel_to_db(table_key: str) -> bool`: 既存のExcelファイルからDBにデータを移行
- `load_master_data(table_name: str, force_reload: bool = False) -> pd.DataFrame`: マスターデータを読み込む（キャッシュ付き）
- `update_table_structure(table_name: str, df: pd.DataFrame) -> bool`: テーブル構造をDataFrameのカラムに合わせて更新
  - 不足しているカラムを自動的に追加
  - カラム名をエスケープ処理（特殊文字対応）
  - データ型を自動推測（INTEGER、REAL、TEXT）
- `save_master_data(df: pd.DataFrame, table_name: str) -> tuple[bool, str]`: マスターデータを保存
  - 戻り値: (成功フラグ, エラーメッセージ)
  - テーブルが存在しない場合は自動作成
  - テーブル構造を自動更新
  - 詳細なエラーハンドリング
- `check_table_has_data(table_name: str) -> bool`: テーブルにデータが存在するか確認
- `get_table_schema(table_name: str) -> list`: テーブルのスキーマ（カラム名）を取得
- `create_empty_dataframe(table_name: str) -> pd.DataFrame`: テーブルのスキーマに基づいて空のDataFrameを作成
- `ensure_table_structure(table_name: str, df: pd.DataFrame) -> bool`: テーブルが存在しない場合、DataFrameの構造に基づいてテーブルを作成
- `close()`: 接続を閉じる

#### 7.4.2 ユーティリティ関数

- `load_master_data_cached(_conn: sqlite3.Connection, table_name: str) -> pd.DataFrame`: マスターデータを読み込む（キャッシュ付き）

### 7.5 エラーハンドリング

- **データフレームの検証**: 空のデータフレームやカラムが定義されていない場合のチェック
- **SQLiteエラーの種類別処理**:
  - `IntegrityError`: データ整合性エラー（重複データ、制約違反）
  - `OperationalError`: データベース操作エラー
  - その他の予期しないエラー
- **トランザクション管理**: エラー時は自動的にロールバック
- **詳細なエラーメッセージ**: UIにエラー詳細を表示し、ログファイルにも記録

### 7.6 使用例

```python
# データベースマネージャーを初期化
db_manager = MasterDatabaseManager(DB_PATH)

# マスターデータを読み込む
df = db_manager.load_master_data("master_employee_code")

# データを編集（Streamlitのdata_editorで）
edited_df = st.data_editor(df, num_rows="dynamic")

# データを保存
success, error_msg = db_manager.save_master_data(edited_df, "master_employee_code")
if success:
    st.success("データを保存しました。")
else:
    st.error(f"保存に失敗しました: {error_msg}")

# 接続を閉じる
db_manager.close()
```

## 10. 非同期処理設計

### 10.1 非同期処理の利点

- レスポンス時間の改善
- リソース効率の向上
- エラーハンドリングの強化
- スケーラビリティの向上

### 10.2 非同期処理パターン

```python
async def process_data():
    async with database.error_handler():
        # データ処理
        result = await data_processor.process()
        # 結果表示
        await display.show_result(result)
```

### 10.3 エラーハンドリング
