```mermaid
graph TD
    A[ユーザーアクセス] --> B[メインページ]

    C -->|pg01| D[管理試料測定結果登録・確認]
    C -->|pg02| E[測定状況登録]
    C -->|pg03| F[精度管理試料測定結果・対応]
    C -->|pg04| G[管理者関係・精度管理実施状況確認]

    H --> J
```
