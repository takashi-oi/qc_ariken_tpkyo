# 有研東京検査所 精度管理システム 仕様書

## 1. システム概要

### 1.1 システム名

有研東京検査所 精度管理システム

### 1.2 システム目的

感染症（病原性腸内細菌）検査（PCR検査）における内部精度管理をWESTGARD multi-Rule手法により実施し、検査精度の維持・向上を図る。

### 1.3 システム構成

- **フロントエンド**: Streamlit Webアプリケーション
- **バックエンド**: Python 3.12（非同期処理対応）
- **データベース**: SQLite（最適化済み）
- **精度管理手法**: WESTGARD multi-Rule

## 3. 機能仕様

### 3.1 主要機能

#### 3.1.1 管理試料測定結果登録・確認 (pg01_qc_check.py)

- **機能**: 管理試料の測定結果を登録・確認
- **入力**: 測定データ（Ct値、SD換算値等）
- **出力**: 測定結果の確認画面
- **WESTGARDルール**: 1-2s, 1-3s, 2-2s, R-4s, 2of3-2s, 4-1s, 8x
- **非同期処理**: データベース操作とファイル処理

#### 3.1.2 測定状況登録 (pg02_test_status.py)

- **機能**: 測定状況の登録・管理
- **入力**: 測定状況情報
- **出力**: 測定状況一覧

#### 3.1.3 精度管理試料測定結果・対応 (pg03_qc_act_log.py)

- **機能**: 精度管理試料の測定結果と対応記録
- **入力**: 測定結果、対応内容
- **出力**: 対応ログ

#### 3.1.4 管理者関係・精度管理実施状況確認 (pg04_confirmation_of_accuracy_control.py)

- **機能**: 管理者向けの精度管理実施状況確認
- **入力**: 期間指定
- **出力**: 精度管理実施状況レポート

#### 3.1.5 精度管理図出力 (pg05_statical.py)

- **機能**: 統計学的精度管理図の作成・出力
- **入力**: 期間指定

## 4. 精度管理手法

### 4.1 WESTGARD multi-Rule

- **1-2s**: 1つの測定値が平均±2SDの範囲外
- **1-3s**: 1つの測定値が平均±3SDの範囲外
- **2-2s**: 連続する2つの測定値が同じ方向で平均±2SDの範囲外
- **R-4s**: 2つの測定値の差が4SD以上
- **2of3-2s**: 3つの測定値のうち2つが同じ方向で平均±2SDの範囲外
- **4-1s**: 連続する4つの測定値が同じ方向で平均±1SDの範囲外
- **8x**: 連続する8つの測定値が平均の同じ側にある

### 4.2 統計的判定基準

- **SD換算値**: -5 ～ +5 の範囲
- **判定**: 各ルールに基づく自動判定
- **対応**: 違反時の対応記録
