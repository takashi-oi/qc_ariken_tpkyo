# データベース設計書

## 1. データベース概要

### 1.1 データベース名

`qc_data_base.db`

### 1.2 データベース種別

SQLite 3.x（最適化済み）

### 1.3 用途

有研東京検査所の精度管理システムにおける測定データ、判定結果、ログ情報の管理

## 2. 最適化テーブル設計

### 2.1 qc_file_info（ファイル情報テーブル）

#### 2.1.1 概要

アップロードされたファイルの基本情報を管理（最適化済み）

#### 2.1.2 テーブル定義

```sql
CREATE TABLE IF NOT EXISTS qc_file_info (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    file_name TEXT NOT NULL,
    date_time DATETIME NOT NULL,
    batch TEXT NOT NULL,
    item_code TEXT NOT NULL,
    model TEXT NOT NULL,
    measurer TEXT NOT NULL,
    lot_number TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(date_time, batch, item_code)
);
```

#### 2.1.3 カラム詳細

| カラム名 | データ型 | NULL | 説明 |
|---------|---------|------|------|
| id | INTEGER | NOT NULL | 主キー（自動採番） |
| file_name | TEXT | NOT NULL | ファイル名 |
| date_time | DATETIME | NOT NULL | 測定日時 |
| batch | TEXT | NOT NULL | バッチ番号 |
| item_code | TEXT | NOT NULL | 項目コード |
| model | TEXT | NOT NULL | 機種名 |
| measurer | TEXT | NOT NULL | 測定者名 |
| lot_number | TEXT | NULL | ロット番号 |
| created_at | DATETIME | NOT NULL | 作成日時 |
| updated_at | DATETIME | NOT NULL | 更新日時 |

#### 2.1.4 インデックス

- `idx_file_info_date_time`: date_time
- `idx_file_info_item_code`: item_code
- `idx_file_info_batch`: batch
- `idx_file_info_measurer`: measurer
- `idx_file_info_date_item`: (date_time, item_code)

### 2.2 qc_measurements（測定データテーブル）

#### 2.2.1 概要

測定データを統合管理（最適化済み）

#### 2.2.2 テーブル定義

```sql
CREATE TABLE IF NOT EXISTS qc_measurements (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    file_info_id INTEGER NOT NULL,
    measurement_type TEXT NOT NULL CHECK (measurement_type IN ('IC', 'NC', 'PC')),
    dye TEXT,
    ct_value REAL,
    sd_conversion REAL,
    verdict TEXT CHECK (verdict IN ('Pass', 'Fail')),
    sample_type TEXT,
    control_limit REAL,
    standard_deviation REAL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (file_info_id) REFERENCES qc_file_info(id) ON DELETE CASCADE,
    UNIQUE(file_info_id, measurement_type, dye)
);
```

#### 2.2.3 カラム詳細

| カラム名 | データ型 | NULL | 説明 |
|---------|---------|------|------|
| id | INTEGER | NOT NULL | 主キー（自動採番） |
| file_info_id | INTEGER | NOT NULL | ファイル情報ID（外部キー） |
| measurement_type | TEXT | NOT NULL | 測定タイプ（IC/NC/PC） |
| dye | TEXT | NULL | 色素 |
| ct_value | REAL | NULL | Ct値 |
| sd_conversion | REAL | NULL | SD換算値 |
| verdict | TEXT | NULL | 判定結果（Pass/Fail） |
| sample_type | TEXT | NULL | サンプルタイプ |
| control_limit | REAL | NULL | 管理限界値 |
| standard_deviation | REAL | NULL | 標準偏差 |
| created_at | DATETIME | NOT NULL | 作成日時 |

#### 2.2.4 インデックス

- `idx_measurements_file_info`: file_info_id
- `idx_measurements_type`: measurement_type
- `idx_measurements_verdict`: verdict
- `idx_measurements_ct_value`: ct_value
- `idx_measurements_sd_conversion`: sd_conversion

### 2.4 qc_westgard_results（Westgard結果テーブル）

#### 2.4.1 概要

Westgardルールの判定結果を管理（最適化済み）

#### 2.4.2 テーブル定義

```sql
CREATE TABLE IF NOT EXISTS qc_westgard_results (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    file_info_id INTEGER NOT NULL,
    measurement_type TEXT NOT NULL,
    rule_1_2s BOOLEAN DEFAULT 0,
    rule_1_3s BOOLEAN DEFAULT 0,
    rule_2_2s BOOLEAN DEFAULT 0,
    rule_r_4s BOOLEAN DEFAULT 0,
    rule_4_1s BOOLEAN DEFAULT 0,
    rule_8x BOOLEAN DEFAULT 0,
```

| カラム名 | データ型 | NULL | 説明 |

| measurement_type | TEXT | NOT NULL | 測定タイプ |
| rule_1_2s | BOOLEAN | NOT NULL | 1-2sルール違反フラグ |
| rule_1_3s | BOOLEAN | NOT NULL | 1-3sルール違反フラグ |
| rule_2_2s | BOOLEAN | NOT NULL | 2-2sルール違反フラグ |
| rule_r_4s | BOOLEAN | NOT NULL | R-4sルール違反フラグ |
| rule_4_1s | BOOLEAN | NOT NULL | 4-1sルール違反フラグ |

#### 2.4.4 インデックス

- `idx_westgard_file_info`: file_info_id
