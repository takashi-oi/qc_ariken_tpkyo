# データベース設計書

## 1. データベース概要

### 1.1 データベース名
`qc_data_base.db`

### 1.2 データベース種別
SQLite 3.x

### 1.3 用途
有研東京検査所の精度管理システムにおける測定データ、判定結果、ログ情報の管理

## 2. テーブル設計

### 2.1 table_qc_file_info（ファイル情報テーブル）

#### 2.1.1 概要
アップロードされたファイルの基本情報を管理

#### 2.1.2 テーブル定義
```sql
CREATE TABLE table_qc_file_info (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    File_Name TEXT NOT NULL,
    Date_Time TEXT NOT NULL,
    Batch TEXT,
    Item_Code TEXT,
    Model TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 2.1.3 カラム詳細
| カラム名 | データ型 | NULL | 説明 |
|---------|---------|------|------|
| id | INTEGER | NOT NULL | 主キー（自動採番） |
| File_Name | TEXT | NOT NULL | ファイル名 |
| Date_Time | TEXT | NOT NULL | 測定日時 |
| Batch | TEXT | NULL | バッチ番号 |
| Item_Code | TEXT | NULL | 項目コード |
| Model | TEXT | NULL | 機種名 |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

#### 2.1.4 インデックス
- `idx_file_name`: File_Name
- `idx_date_time`: Date_Time
- `idx_item_code`: Item_Code

### 2.2 table_qc_nc（NC判定情報テーブル）

#### 2.2.1 概要
管理試料のNC判定結果を管理
